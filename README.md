# ✦ FocusFlow AI — Smart Study Planner

**Make today count. Turn your goals into achievements.**

FocusFlow AI is a modern, student-friendly study planner built using HTML, CSS, and JavaScript. It helps students organize daily study tasks, track their progress, and stay focused with a built-in Pomodoro timer.

The project features a premium dark interface, smooth animations, and a responsive layout that works across desktop and mobile devices.

## ✨ Features

- 📋 **Task Management:** Add, complete, and delete study tasks.
- 🎯 **Priority Levels:** Organize tasks by High, Medium, and Low priority.
- ⏱️ **Pomodoro Timer:** Use a 25-minute focus session to improve concentration.
- 📊 **Progress Tracking:** View total tasks, completed tasks, and completion percentage.
- 💾 **Local Storage:** Keep tasks saved in your browser.
- 📱 **Responsive Design:** Use the interface on desktop, tablet, and mobile.
- 🎨 **Modern UI:** Dark theme, purple gradients, and smooth hover animations.

## 🚀 Getting Started

### Prerequisites

- A modern web browser such as Chrome, Edge, or Firefox.
- Visual Studio Code (optional).
- No package installation or backend server is required.

### Run Locally

1. Download or clone this repository.
2. Open the `focusflow-ai` folder in Visual Studio Code.
3. Open `index.html` directly in your browser, or run it using the Live Server extension.
4. Start adding tasks and try the focus timer.

To clone your own GitHub repository, replace the placeholder URL below with your repository URL:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd focusflow-ai
```

## 📖 How to Use

1. Open FocusFlow AI in your browser.
2. Enter a study task, such as `Learn C programming`.
3. Select a priority: High, Medium, or Low.
4. Click **Add** to add the task to your planner.
5. Mark a task as completed using its checkbox, or delete it when it is no longer needed.
6. Check the dashboard to see your total tasks, completed tasks, and progress percentage.
7. Click **Start** to begin a 25-minute focus session.
8. Use **Pause** to pause the timer and **Reset** to start a fresh session.

Your tasks are saved in the current browser's local storage and can persist between visits in that browser.
